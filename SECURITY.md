# Security

The threat model is in [`docs/security.md`](docs/security.md).

## Reporting a vulnerability

Please report privately through [GitHub's vulnerability reporting](https://github.com/ZahakJ/jaunt/security/advisories/new) rather than in a public issue. Include the version, how your machines are connected (relay, direct, same LAN), the steps, and what an attacker gains. You will get an acknowledgement within a week and a fix or a reasoned answer as soon as one exists.

## Supported versions

The latest release only.
