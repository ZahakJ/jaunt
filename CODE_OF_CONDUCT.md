# Code of conduct

This project is maintained by one person in their spare time, with help from anyone who wants to give it. The rules are short.

- Be courteous. Disagree with ideas, not with people.
- Assume good faith; ask before concluding.
- No harassment, no personal attacks, no discrimination of any kind, in issues, pull requests, reviews or anywhere the project is discussed.
- Keep private things private: no hostnames, addresses or logs from machines that are not yours.

If something goes wrong, write to the maintainer through a GitHub issue, or privately through the repository's security advisory form if it should not be public. Reports are read and acted on; the usual response to a serious breach is removal from the project's spaces.
